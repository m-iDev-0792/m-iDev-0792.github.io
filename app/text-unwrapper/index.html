LaTeX & Markdown Unwrapper

Rejoin hard-wrapped paragraphs into single lines. Only line breaks caused by wrapping are joined; breaks at blank lines, headings, list items, quotes, comments, \\, code blocks, tables and math environments stay as they are.

LaTeX: blank line → protected environment (tabular align lstlisting …) → trailing % comment → trailing \\ → unclosed brace (treated as a continuation, so it is joined) → previous line is a standalone command → next line starts with a structural command, & or $$.

Markdown: blank line → protected block (``` fences, indented code, tables, $$ math, front matter, HTML) → hard break (two trailing spaces or a trailing \) → heading or horizontal rule → list item → change in quote depth → footnote or link definition. Continuation lines at the same > depth are joined with their prefix removed.

A line break is joined only when none of these rules apply. Auto guesses the syntax from the content. You can drop a .tex or .md file onto the input pane. Everything runs locally in your browser.
